# YouTube Faceless Niche Finder 🔥

2026 ke best faceless YouTube channels dhundo — competition analysis ke saath!

## Setup (Ghar pe ya kisi bhi PC pe)

### Step 1 — Python install karo
https://python.org/downloads (3.10+)

### Step 2 — Repo clone karo
```
git clone https://github.com/TUMHARA_USERNAME/youtube-niche-finder.git
cd youtube-niche-finder
```

### Step 3 — Dependencies install karo
```
pip install flask requests
```

### Step 4 — API Key lagao
1. `config.example.py` ko copy karo → naam `config.py` rakho
2. `config.py` kholke apni YouTube API key daalo
3. API key yahan se milegi: https://console.cloud.google.com

```python
YOUTUBE_API_KEY = "AIzaSy...apni_key_yahan"
```

### Step 5 — Run karo
```
python app.py
```
Ya double-click karo `START.bat`

### Step 6 — Browser mein kholo
```
http://localhost:5000
```

- 11 Faceless Niches scan karta hai
